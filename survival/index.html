Bedrock Players

Bedrock users on PC, phone/tablet can use the Ip and port to add Bjornie Survival to their server list. Make sure you are on the latest version of Minecraft, otherwise you may end up dying in a pit of fire.
Bedrock users on console do not have a built in ability to add custom servers, so they have to follow a tutorial specific to their console to change their DNS settings. YouTube tutorials are always completely trustworthy!!!!!! Additionally, players on console need their console's subscription to give them the ability to play online (Xbox Game Pass, Switch Online, etc.).
Bedrock users, try these DNS settings. (Xbox, go to your settings app/General/Network Settings/Advanced settings/DNS Settings. There should be an advanced setting option or something idk)
Primary: 139.59.200.206
Secondary: 8.8.8.8
You can lookup a tutorial on YouTube, but I recommend using these DNS settings instead of their likely outdated ones. If these DNS settings do not work, please directly message me. Also if you are worried about what this does, you can ask about that too and I can try my best to explain :)
Attempt to connect with the primary DNS setting on the featured Minecraft servers, some work, some don't, LifeBoat worked last time I tested, I'm not sure if that's changed somehow though.
